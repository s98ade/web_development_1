Detecting Key Presses

Create a program that shows the last key pressed and its key code.

Press any key...

  • Add a keydown listener to the document.
  • First, print the event to the console.
  • Show:
    • the pressed key (event.key)

  • Add a counter that shows the number of key presses.
  • Show whether Shift, Ctrl, or Alt is pressed.

Bonus Exercise: Google Maps and Geolocation

1. Google Maps and Coordinates

You can open Google Maps at a specific location by adding coordinates to the URL:

https://www.google.com/maps?q=60.1699,24.9384

2. Finding the User’s Location (Geolocation API)

You can find the user’s location with JavaScript’s Geolocation API. 

navigator.geolocation.getCurrentPosition(
    (position) => {
        console.log("Latitude:", position.coords.latitude);
        console.log("Longitude:", position.coords.longitude);
    },
    (error) => {
        console.log("Could not get the location:", error.message);
    }
);

After you have the coordinates, you can direct the user to Google Maps:

const url = `https://www.google.com/maps?q=${lat},${lon}`;
window.location.href = url;

Note: location access usually works only on HTTPS pages.
